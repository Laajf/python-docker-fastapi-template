# python-docker-fastapi-template

Шаблон бэкенда, который я собираю под свои проекты, чтобы каждый раз не настраивать с нуля одно и то же: докер, базовый CRUD, очереди и связку сервисов.

Цель — сделать каркас, который можно просто склонировать и сразу писать бизнес-логику, не тратя полдня.

### Что в планах (Roadmap)

- [x] **VS Code + Docker**
  - Dev Containers 
- [ ] **Базовый каркас кода**
  - Разделение по слоям: роуты, сервисы, схемы (Pydantic), модели
  - Централизованный конфиг через `.env` и Pydantic Settings
- [ ] **Связка микросервисов**
  - Соединить docker-compose с основными микросервисами
- [ ] **Отложенные задачи и воркеры**
  - Настроить выполнение тяжелых задач по очереди и в определенное время (Redis)
- [ ] **База данных и базовый CRUD**
  - Подключение СУБД (PostgreSQL + SQLAlchemy)
  - Накатка миграций через Alembic
- [ ] Собрать фидбек и докрутить фичи под реальные сценарии
