# python-docker-fastapi-template

Шаблон бэкенда, который я собираю под свои проекты, чтобы каждый раз не настраивать с нуля одно и то же: докер, линтеры, базовый CRUD, очереди и связку сервисов.

Цель — сделать каркас, который можно просто склонировать и сразу писать бизнес-логику, не тратя полдня.

### Что в планах (Roadmap)

- [ ] **VS Code + Docker**
  - Dev Containers / нормальный запуск внутри контейнера без боли с путями
  - Конфиг линтеров (ruff/flake8) и форматтеров под сохранение файлов
- [ ] **Базовый каркас кода**
  - Разделение по слоям: роуты, сервисы, схемы (Pydantic), модели
  - Централизованный конфиг через `.env` и Pydantic Settings
- [ ] **Связка микросервисов**
  - Соединить docker-compose с основными микросервисами
  - Готовый пример межсервисного взаимодействия
- [ ] **Отложенные задачи и воркеры**
  - Настроить выполнение тяжелых задач по очереди и в определенное время (Celery / Taskiq / Redis)
- [ ] **База данных и базовый CRUD**
  - Подключение СУБД (PostgreSQL + SQLAlchemy / asyncpg)
  - Накатка миграций через Alembic
- [ ] Собрать фидбек и докрутить фичи под реальные сценарии
